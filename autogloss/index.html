✨ Auto-gloss with Gemini

Autogloss has no server, so it uses your Google Gemini API key. Create a free one at Google AI Studio, then paste it below. It is stored only in this browser and sent only to Google.

Anyone with access to this browser profile could read the key. Don't use a shared or public computer, and consider restricting the key to the Generative Language API in Google Cloud.

Always check the output. AI glossing is reasonable for large, well-documented languages and unreliable for under-resourced ones. Treat every result as a first draft to correct, not a finished analysis.
